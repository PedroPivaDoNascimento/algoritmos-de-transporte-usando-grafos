# 📖 Modo de Uso Detalhado
## 1. Compilar o Projeto

Para apenas compilar todo o código-fonte sem executá-lo:
```bash
make
```
## 2. Compilar e Rodar o Programa

Para compilar (se necessário) e executar o projeto diretamente no terminal:
```bash
make run
```

## 3. Limpar Arquivos de Build (obj e bin)

Para remover todos os arquivos temporários criados durante a compilação (.o) e o arquivo executável final:
```bash
make clean
```
